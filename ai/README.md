# ai

The Python service for AI capabilities: a modular monolith serving gRPC on port 50051. It has no
route and no published port; backend reaches it as `ai:50051` on the Compose network. Its contract
lives in the root [`proto/`](../proto/).

## Stack

| Concern | Choice |
| --- | --- |
| Language | Python 3.14, pinned in the root `devbox.json` |
| Packaging | uv, with hatchling building the `aisvc` package; locked in `uv.lock` |
| RPC | grpcio's thread-pool server, with stubs generated by buf into `gen/` |
| Config | pydantic-settings, from environment variables only |
| Logging | structlog |
| Hot reload | watchfiles, in the dev image only |
| Lint | Ruff, mypy in strict mode, and import-linter for the import boundaries |
| Tests | pytest, with pytest-socket allowing loopback only |

## Project structure

```
ai/
├── gen/                    # generated code: the ai.v1 Python stubs, from ../proto
├── scripts/                # lint steps run by `turbo run lint`
├── docs/adr/               # decisions scoped to ai
├── src/aisvc/
│   ├── __main__.py         # composition root: `python -m aisvc serve` and `healthcheck`
│   ├── platform/           # config, logging, build info
│   ├── rpc/                # server assembly, module registration, the Info and health servicers,
│   │                       #   the request-ID interceptor, the error guard, the graceful stop
│   └── modules/            # one AI capability each, shaped as:
│       └── <m>/
│           ├── __init__.py # public interface: register(server)
│           ├── model.py    # shape-only types
│           └── _internal/  # servicer, service and provider adapters; private to the module
└── tests/                  # mirrors src/aisvc/
```

No module exists yet, so `src/aisvc/modules/` is empty; `<m>/` shows the shape each one takes. The Python package is `aisvc` because the
generated code owns the top-level `ai`; the npm workspace is still named `ai`.

The rules behind this layout are in [`CLAUDE.md`](./CLAUDE.md), and the reasons in
[`docs/adr/`](./docs/adr/).

## Commands

Run from the repository root inside `devbox shell`.

| Command | Does |
| --- | --- |
| `make dev` | Starts the stack, with ai reloading on every save under `ai/src` |
| `make check` | Lints and tests every workspace, then smoke-tests the stack |
| `npm run lint -w ai` | Lock check, Ruff lint and format check, strict mypy, then import-linter |
| `npm run lint:fix -w ai` | Applies Ruff's safe fixes, then formats with Ruff |
| `npm run test -w ai` | Runs pytest |
| `python -m aisvc healthcheck` | Inside the container: exits 0 when the local server answers `SERVING`, else 1 |

## RPCs

| RPC | Answers |
| --- | --- |
| `ai.v1.InfoService/GetInfo` | `{service: "ai", version}` while the process runs |
| `grpc.health.v1.Health/Check`, `Watch` | `SERVING` for `""` (readiness) and `ai.v1.InfoService` once started; both turn `NOT_SERVING` when shutdown begins |
