# backend

The Go API: a modular monolith and the only client of PostgreSQL. It serves HTTP under `/api` behind
Traefik, and calls ai over gRPC through a generated client.

## Stack

| Concern | Choice |
| --- | --- |
| Language | Go 1.27, pinned in the root `devbox.json` |
| HTTP | gin, with a strict server generated by oapi-codegen from `api/openapi.yaml` |
| Database | PostgreSQL through sqlx and the `pgx/v5/stdlib` driver, one schema per module |
| Migrations | golang-migrate, forward-only in production |
| Config | caarlos0/env, from environment variables only |
| Logging | zap |
| Hot reload | air, in the dev image only |
| Tests | `go test`, `httptest` |

## Project structure

```
backend/
├── api/openapi.yaml        # the HTTP contract
├── cmd/
│   ├── server/             # the API
│   ├── migrate/            # applies the embedded migrations
│   └── seed/               # dev-only seed data
├── gen/                    # generated code: gRPC client for ai, OpenAPI server
├── migrations/             # SQL migrations, one flat folder
├── scripts/                # lint steps run by `turbo run lint`
└── internal/
    ├── platform/           # config, logging, database, ai connection, errors, build info
    ├── api/                # HTTP composition, envelope, error mapping, health, docs
    └── modules/<module>/   # one bounded context each: public.go, model/, internal/
```

No module exists yet, so `internal/modules/` is empty. `internal/bff/`, for endpoints that combine
several modules, arrives with the first endpoint that needs two of them.

The rules behind this layout are in [`CLAUDE.md`](./CLAUDE.md), and the reasons in
[`docs/adr/`](./docs/adr/).

## Commands

Run from the repository root inside `devbox shell`.

| Command | Does |
| --- | --- |
| `make dev` | Starts the stack: migrates, seeds, then runs backend with hot reload |
| `make check` | Lints and tests every workspace, then smoke-tests the stack |
| `npm run lint:fix -w backend` | Formats every Go file with `gofmt -w` |
| `make migrate-create name=<module>_<desc>` | Creates a new up/down migration pair |
| `make migrate-up` | Applies pending migrations (also part of `make dev`) |
| `make migrate-version` | Shows the current version and whether the database is dirty |
| `make migrate-down` | Reverts the last migration — dev only |
| `make migrate-redo` | Reverts and reapplies the last migration — dev only |
| `make migrate-force version=<n> confirm=<database>` | Clears the dirty flag after a failed migration |
| `make seed` | Re-runs the seed data — dev only |
| `make db-reset` | Drops the dev database, then migrates and seeds — dev only |

## Endpoints

| Path | Answers |
| --- | --- |
| `GET /api/health` | 200 with `{version, environment}` while the process runs |
| `GET /api/health/ready` | 200, or 503 when PostgreSQL is unreachable |
| `GET /api/docs` | Swagger UI — dev and staging only |
| `GET /api/openapi.json` | The OpenAPI spec as JSON — dev and staging only |
